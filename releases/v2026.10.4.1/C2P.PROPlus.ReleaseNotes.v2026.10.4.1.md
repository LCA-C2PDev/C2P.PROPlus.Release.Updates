# Call2Prayer PROPlus 2026.10.4.1 Preview

Channel: preview

Tag: preview-v2026.10.4.1

Package: C2P.PROPlus.Update.v2026.10.4.1.zip

This preview advances the Scheduler preview released on 2026.10.1.1. Settings → About now shows the features and interface details from the installed license, followed by direct support, product, privacy, and warranty links.

The release accepts signed `C2P.License/v2` licenses issued through the License Requester and SAK Fingerprint V2 workflow. Its stable hardware identity excludes network adapters, so an adapter change does not invalidate a v2 license. Legacy v1 licenses remain supported, including a constrained MAC-change compatibility path when their signed hardware evidence is strong and unchanged.

The Scheduler workspace fix, licensed audio behavior, and optional USB relay behavior from the prior preview remain. The update supports installed version `2026.9.6.1` or later. The stable installer and stable update channel remain unchanged.

The Release app and test projects built, all 128 automated tests passed, and the update ZIP passed package validation and isolated apply, bad-hash, and unsafe-path checks. Physical USB behavior and target-PC v1/v2 license acceptance remain part of operator preview testing. Do not share license contents or machine evidence in test reports.
