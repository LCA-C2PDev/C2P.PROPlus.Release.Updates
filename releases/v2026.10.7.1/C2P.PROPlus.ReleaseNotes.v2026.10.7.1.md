# Call2Prayer PROPlus 2026.10.7.1 Stable

Channel: stable

Tag: v2026.10.7.1

Package: C2P.PROPlus.Update.v2026.10.7.1.zip

This minor update adds the opt-in Scheduler choice **Pause during prayer, then resume**. A playing scheduled event pauses at its current media position when prayer takes priority, keeps its repeat progress, and resumes after the complete prayer workflow. The resumed sound rises smoothly using the event's configured Fade in duration. The event's Maximum Duration continues to run during prayer.

The update retains prayer/Athan/Dua authority, Scheduler entitlement and data compatibility, AudioManager arbitration, and existing manual emergency controls. The separately distributed full installer remains v2026.9.6.1. The Preview feed remains at v2026.10.6.1.

The self-contained win-x64 application and updater were built. All 136 automated tests passed in the Stable Release worktree. The ZIP passed compatibility validation with the previous Stable updater and isolated apply, bad-hash, and unsafe-path checks. SHA-256: `34E5BC40DE889B45B58957547834EF373A4719B468B201BEB96CFF25B67C27F7`.

Real audio fade quality, licensed relay timing, activation, and operation on a target PC still require operator verification. This application update is intended for existing installations; it is not a full installer.
