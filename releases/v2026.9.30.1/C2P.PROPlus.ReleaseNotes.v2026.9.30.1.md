# Call2Prayer PROPlus 2026.9.30.1 Preview

Channel: preview

Tag: preview-v2026.9.30.1

Package: C2P.PROPlus.Update.v2026.9.30.1.zip

This preview adds a calendar for licensed scheduled audio. AudioManager now makes a smooth handover to scheduled playback, and optional USB relay control follows the audio transition. The Settings window also has an About tab with the installed version, recent highlights, and update information.

The update supports installations running version `2026.9.6.1` or later. Existing schedules and local application data remain in place during the update. The stable release and its original installer are unchanged.

The package passed compatibility validation with the stable updater and an isolated apply test, including checks that user data folders were preserved and invalid packages were rejected.
