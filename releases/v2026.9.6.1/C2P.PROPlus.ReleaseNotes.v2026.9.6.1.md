# Call2Prayer.PROPlus 2026.9.6.1

Channel: stable

Tag: v2026.9.6.1

Package: C2P.PROPlus.Update.v2026.9.6.1.zip

This release changes the module name from **MusicManager** to **AudioManager** throughout the application UI, settings, documentation, and internal component names. Audio playback behavior remains unchanged.

Existing licenses containing the legacy `MusicManager` entitlement remain valid. New licenses can use `AudioManager`. Existing MusicManager configuration, dashboard layout, and media locations are migrated for backward compatibility.

The update package was validated by the deployed compatibility updater and exercised in an isolated updater sandbox before Stable publication.
