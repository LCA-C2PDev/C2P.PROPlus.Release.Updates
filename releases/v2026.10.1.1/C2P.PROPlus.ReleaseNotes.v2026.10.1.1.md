# Call2Prayer PROPlus 2026.10.1.1 Preview

Channel: preview

Tag: preview-v2026.10.1.1

Package: C2P.PROPlus.Update.v2026.10.1.1.zip

This preview fixes the Scheduler **Open Workspace** button. When the calendar is already open, the button now brings that window forward instead of opening another calendar. A minimized calendar is restored; closing it allows a new calendar to open later.

The preview retains the licensed Scheduler, audio handover, and optional USB relay behavior introduced in 2026.9.30.1. It supports installations running version `2026.9.6.1` or later. The original stable installer and stable update channel are unchanged.

The package passed automated tests, compatibility validation with the stable updater, and isolated apply checks. Physical USB relay timing and disconnect/reconnect behavior remain part of final operator testing.
